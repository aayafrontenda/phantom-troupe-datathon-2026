# Заметки по обучающему датасету

- 40 файлов `.mov`, 42 строки разметки (`open_labels.xlsx`): 22 метки «нарушение» с таймкодом, 20 «без нарушения».
- 464×848, 30 fps, H.264, без звука, длительность 11–143 с.
- **Дубли:** Х-4 и Х-47 — один и тот же файл (md5 совпадает), метки 57 с и 68 с → в одном видео бывает несколько нарушений.
  Х-5 и Х-48 — тоже один файл (оба без нарушений).
- Постановочные сцены, одна касса, несколько расстановок мебели и ракурсов (A–E в `ml/eval/labels_typed.csv`):
  - A — кассир спиной к камере, клиент напротив, сейф справа (Х-1…Х-5, Х-16…Х-19);
  - B — вид сбоку, стол внизу кадра, сейф у двери (Х-8, Х-10…Х-15, Х-20…Х-29);
  - C — зеркальная расстановка: телефон слева, счётная машина справа (Х-30…Х-32);
  - D — синий стул клиента, кассир лицом к камере (Х-33, Х-40…Х-46);
  - E — кассир спиной, ноутбук слева, сейф справа (Х-34…Х-39).
- Финальное видео жюри будет снято под другим углом (FAQ 4) — фиксированные зоны не использовать.
- Таймкод в разметке — момент, когда нарушение становится видно (кассир встаёт и уходит, входит следующий клиент,
  кассир берёт деньги). Для нарушений «по бездействию» — момент, когда действие должно было произойти.
- Тип нарушения в разметке не указан; типы T01–T15 в `labels_typed.csv` проставлены вручную по просмотру.
- В тесте могут быть типы, которых нет в обучающих (FAQ 9).
