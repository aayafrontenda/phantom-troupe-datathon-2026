# Claude Code в VS Code — туториал для этого проекта

Как работать над `forte-cashguard` в VS Code с Claude Code: установка, управление, готовые запросы по шагам ML-задачи.
Факты об инструменте — по официальной документации: [VS Code](https://code.claude.com/docs/en/vs-code),
[установка](https://code.claude.com/docs/en/setup), [CLAUDE.md и память](https://code.claude.com/docs/en/memory).

---

## 1. Установка (один раз)

1. **VS Code 1.94 или новее.**
2. **Расширение:** `Ctrl+Shift+X` → в поиске «Claude Code» (издатель Anthropic) → **Install**.
3. **Вход:** при первом открытии панели войдите аккаунтом Claude — нужен платный план (Pro, Max, Team, Enterprise)
   или аккаунт Console. Бесплатный план Claude Code не включает.
4. **Git for Windows** (git-scm.com) — желательно: с ним Claude запускает команды через Git Bash; без него — через PowerShell.
5. **CLI в терминале** — не обязателен. Расширение несёт свою копию; отдельно ставится только если хотите запускать
   `claude` во встроенном терминале:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   claude --version
   ```

## 2. Открыть проект

1. **File → Open Folder** → `C:\Users\zhuma\Documents\DATATHON\forte-cashguard`.
2. Откройте любой файл → иконка-искра справа вверху над редактором (или искра на левой панели) → панель Claude.
3. Claude при старте читает `CLAUDE.md`, а он подключает `AGENTS.md` — весь контекст кейса: ТЗ, ограничения,
   устройство кода, типы нарушений. Проверка: спросите «Кратко: что это за проект и какие ограничения нельзя нарушать?»
4. Если что-то надо добавить в постоянный контекст (например, найденный порог) — правьте `AGENTS.md`, его видят и все в команде.

## 3. Управление — главное

| Что | Как |
| --- | --- |
| Режим работы | индикатор внизу поля ввода: **Manual** — спрашивает перед правками и командами; **Plan** — сначала план, потом действия; **Edit automatically** — правит без вопросов; **Auto** — классификатор пропускает безопасные действия |
| Сначала план | `/plan <задача>` — план открывается документом, можно оставить комментарии, потом одобрить |
| Дать файл | `@ml/pipeline.py` (работает частичный ввод) |
| Дать кусок кода | выделить в редакторе → `Alt+K` вставит ссылку вида `@ml/signals.py#40-60` |
| Откатить правки | навести на сообщение → кнопка отката → **Rewind code to here** |
| Переключить фокус редактор ↔ Claude | `Ctrl+Esc` |
| Новый разговор во вкладке | `Ctrl+Shift+Esc` |
| Сменить модель | `/model` |
| Все команды расширения | `Ctrl+Shift+P` → «Claude Code» |

Советы:
- **Одна задача — один разговор.** Длинные разговоры засоряют контекст; для новой задачи — новая вкладка.
- **Крупные изменения — через Plan.** Многофайловая правка без плана — частая причина «сломал соседнее».
- **Всегда просите проверку:** «после правки запусти `pytest -q` и `python -m ml.eval.evaluate … --only …`».
- **Конкретика в запросе:** файл, что изменить, как понять, что получилось.

## 4. Работа по шагам (готовые запросы)

Копируйте в поле ввода. Шаги идут в порядке `docs/tasks/ML.md`.

**Шаг 1. Окружение**
```
Настрой окружение на этом Windows-ноутбуке по docs/tasks/ML.md, раздел 0. Создай .venv, поставь
requirements.txt, torch с CUDA и ml/requirements-ml.txt. Проверь torch.cuda.is_available() и что Ollama
отвечает на http://127.0.0.1:11434 с моделью qwen2.5vl:7b. Команды запускай по одной и показывай вывод.
```

**Шаг 2. Первый запуск модели**
```
Запусти pytest -q, затем python -m ml.cli "data\open\videos\X-1.mov" --no-images.
Если детектор или VLM падают — найди причину и почини. Покажи meta.candidates, meta.scenes и время.
```

**Шаг 3. Базовая оценка**
```
Запусти python -m ml.eval.evaluate --videos data\open\videos. Сделай таблицу пропусков (FN) и ложных (FP)
с причиной по каждому: что увидел детектор (meta.candidates), что ответила VLM (meta.scenes, raw_findings).
Ничего не меняй, только анализ.
```

**Шаг 4. Проход по визитам (самый большой выигрыш)**
```
/plan Реализуй второй проход по визитам из docs/tasks/ML.md, пункт 3.1: интервалы, когда у стола >= 2 человек,
один вызов VLM на визит с 6–8 кадрами и конкретными вопросами для T06, T07, T09, T10. Отдельный промпт в
ml/prompts/, таймкоды по полю timecode в ml/rules_kb.yaml. Проверка: evaluate --only 1,2,4,34,38,47 --force.
```

**Шаг 5. Экран и уход кассира (T01–T03)**
```
Посчитай signals.screen_brightness по кадрам видео 22, 23, 28, 29 до и после ухода кассира и подбери
SCREEN_ON_V, который отделяет включённый экран от заблокированного. Затем добавь кандидата «кассир ушёл от стола»
по трекам людей и вопросы VLM про экран, деньги на столе и дверцу сейфа. Проверка: evaluate --only 11,15,20,22,23,24,25,26,28,29 --force.
```

**Шаг 6. Таймкоды**
```
По report.csv посмотри dt_sec. Если VLM систематически ошибается во времени — бери время из сигнала
(момент, когда человек встал или вошёл), а VLM оставь для подтверждения типа. Цель — медиана ≤ 2 с.
```

**Шаг 7. Скорость**
```
Замерь время на самом длинном видео (14) и на 5 видео подряд через tools/smoke_test.py против локального
сервиса. Если больше 60 с на видео — предложи, что урезать (MAX_VLM_CALLS, VLM_IMAGE_SIDE, кадры на вызов),
и проверь, что метрики не просели.
```

**Шаг 8. Устойчивость к ракурсу**
```
Посчитай метрики по ракурсам A–E из report.csv. Проверь, что в коде нет координат и зон, привязанных к одному
ракурсу. Прогони ml.cli на роликах из data\own\ (наши съёмки под новым углом) и опиши ошибки.
```

## 5. Git

```
Покажи git status. Закоммить изменения в ветку ml с понятным сообщением на русском — без data/, storage/, .env.
```
Перед слиянием в `main`: «подтяни origin/main, реши конфликты, прогони pytest». Для pull request нужен GitHub CLI
(`winget install GitHub.cli`, затем `gh auth login`) — тогда можно просить «открой PR в main».

## 6. Чего не делать (Claude это знает из AGENTS.md, но проверяйте)

- Облачные AI-API в коде — запрещены ТЗ, даже «для проверки».
- Новая модель — только после проверки лицензии на коммерческое использование (Ultralytics YOLO — AGPL, нельзя).
- Обязательные поля ответа API не трогать — `ml/schema.py` и тесты должны оставаться зелёными.
- Тестовые видео жюри не использовать для подбора параметров.
- Нормы — только из `ml/rules_kb.yaml`; новую норму добавлять с дословной цитатой и ссылкой на adilet.

## 7. Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| `Activate.ps1 cannot be loaded` | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, перезапустить терминал |
| `torch.cuda.is_available()` = False | поставили CPU-сборку torch: переустановить с `--index-url` под вашу CUDA (pytorch.org) |
| VLM: `Connection refused` | запустить приложение Ollama или `ollama serve`; проверить `ollama list` |
| `CUDA out of memory` | `VLM_IMAGE_SIDE=384`, `VLM_FRAMES_PER_CALL=4` в `.env`; закрыть другие GPU-программы |
| Видео не открывается | путь с кириллицей обрабатывается `ml/video.ascii_path`; проверьте, что файл целый |
| Claude не видит контекст проекта | открыта не та папка — нужен корень `forte-cashguard`, где лежат `CLAUDE.md` и `AGENTS.md` |
